# 🎨 Watermarking Guide for AI Meme Generator

This guide explains how to add and customize watermarks on your generated memes.

## 🚀 Quick Start

1. **Set up your watermark** by adding these to your `.env` file:
```bash
WATERMARK_STYLE=branded
WATERMARK_TEXT=@YourMemeBot
```

2. **Generate a meme** - watermarks are automatically applied:
```bash
curl "http://localhost:8000/generate_meme?prompt=funny cat meme"
```

3. **Done!** Your memes now have your custom watermark.

## 🎛️ Configuration Options

### Environment Variables

Add these to your `.env` file to customize watermarks:

```bash
# Watermark Style (preset configurations)
WATERMARK_STYLE=branded          # Options: subtle, branded, professional, corner_logo, custom

# Custom Text (overrides style presets)
WATERMARK_TEXT=@YourBrand        # Your watermark text

# Position (for custom style)
WATERMARK_POSITION=bottom-right  # Options: bottom-right, bottom-left, top-right, top-left, center

# Opacity (transparency)
WATERMARK_OPACITY=0.7           # 0.0 (invisible) to 1.0 (opaque)

# Margin from edges
WATERMARK_MARGIN=20             # Pixels from image edge
```

## 🎨 Preset Styles

### 1. **Subtle** 
- Text: "AI Generated"
- Position: Bottom-right
- Low opacity (0.5)
- White text with black background

### 2. **Branded** (Recommended)
- Your custom text
- Yellow text with black background
- High visibility (0.8 opacity)
- Perfect for social media

### 3. **Professional**
- Text: "Generated by AI • Not for commercial use"
- Bottom-center position
- Disclaimer-style watermark

### 4. **Corner Logo**
- Small "🤖 AI" text
- Top-right corner
- Minimal and clean

## 🖼️ Image Watermarks

You can also use image/logo watermarks:

1. **Create your logo** (PNG with transparency recommended)
2. **Save it** as `watermark_assets/your_logo.png`
3. **Use the image watermark** in code:

```python
from util import add_watermark

watermarked_path = add_watermark(
    image_path="your_image.png",
    watermark_image_path="watermark_assets/your_logo.png",
    position="bottom-right",
    opacity=0.7
)
```

## 🔧 Advanced Customization

### Custom Watermark Function

```python
from util import add_watermark

# Apply custom watermark
watermarked_path = add_watermark(
    image_path="generated_images/meme.png",
    watermark_text="© YourBrand 2025",
    position="bottom-center",
    opacity=0.8,
    font_color=(255, 215, 0),  # Gold color
    background_color=(0, 0, 0),  # Black background
    margin=25
)
```

### Color Options

Common color combinations:
```python
# White text, black background (classic)
font_color=(255, 255, 255), background_color=(0, 0, 0)

# Yellow text, black background (high visibility)
font_color=(255, 255, 0), background_color=(0, 0, 0)

# Black text, white background (clean)
font_color=(0, 0, 0), background_color=(255, 255, 255)

# Gold text, dark background (premium)
font_color=(255, 215, 0), background_color=(25, 25, 25)

# Red text, transparent background (attention-grabbing)
font_color=(255, 0, 0), background_color=None
```

## 🎯 Best Practices

### 1. **Positioning**
- **Bottom-right**: Most common, doesn't interfere with meme text
- **Top-right**: Good for logo-style watermarks
- **Bottom-center**: Best for disclaimers
- **Avoid center**: Can interfere with meme content

### 2. **Opacity**
- **0.5-0.6**: Subtle, doesn't distract
- **0.7-0.8**: Good visibility, recommended
- **0.9-1.0**: Maximum visibility, may be distracting

### 3. **Text Content**
- **Short is better**: "@YourBrand" > "Generated by YourBrand AI System"
- **Include @**: Makes it social media friendly
- **Avoid special characters**: Stick to letters, numbers, @, #

### 4. **Colors**
- **High contrast**: Ensure readability
- **Brand colors**: Use your brand's color scheme
- **Background**: Add background for better readability

## 🛠️ Troubleshooting

### Watermark Not Appearing
1. Check `.env` file is loaded correctly
2. Verify `WATERMARK_STYLE` is set
3. Check logs for error messages
4. Ensure Pillow is installed: `pip install Pillow>=10.0.0`

### Image Quality Issues
1. Reduce opacity if watermark is too prominent
2. Adjust margin for better positioning
3. Use PNG format for logo watermarks
4. Check image size - very small images may not show watermarks well

### Font Issues
1. Script attempts to use system fonts automatically
2. Falls back to default font if system fonts unavailable
3. Font size is automatically calculated based on image size
